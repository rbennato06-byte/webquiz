# Fonti

Documenti (slide dei corsi, "sbobine"/quaderni di studio e syllabus
ministeriali) da cui sono state ricavate le domande del quiz e gli appunti
del sito. Sono raccolti qui per comodità di consultazione e per facilitare
la scrittura di nuove domande sugli stessi argomenti (o su argomenti non
ancora coperti).

Organizzati per materia, con nomi di file normalizzati (l'originale
caricato aveva spesso prefissi/hash o nomi meno leggibili).

ministeriali ufficiali.
